# Changelog

## 0.1.0 (2026-09-15)

First release.

- Probabilistic Sharpe Ratio, Deflated Sharpe Ratio, expected maximum Sharpe ratio, minimum track record length and minimum backtest length.
- Sample moments, Sharpe ratio and trial variance from return series, and a one-call DSR from returns.
- Annualised and per-period conversions and an AR(1) effective sample size.
- `dsr` command-line tool with text and JSON output.
- Tests reproducing every numerical example in the three source papers, plus Monte Carlo calibration tests.
